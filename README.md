# 💈 Barber Shop — Website Oficial

Um site moderno, elegante e responsivo desenvolvido para facilitar o agendamento de serviços, apresentação de cortes e atendimento ao cliente de uma barbearia premium.

---

![Demonstração do Site Barber Shop](https://images.unsplash.com/photo-1503951914875-452162b0f3f1?q=80&w=1200&auto=format&fit=crop)

---

## ✨ Funcionalidades

- 📱 **Design Responsivo:** Adaptado para celulares, tablets e desktops.
- ✂️ **Catálogo de Serviços:** Apresentação de cortes, barba, tratamentos e tabela de preços.
- 📅 **Agendamento Online:** Formulário interativo para seleção de data, horário e barbeiro.
- 🖼️ **Galeria de Fotos:** Portfólio com fotos dos cortes e do ambiente da barbearia.
- 📍 **Localização e Contato:** Integração com Google Maps, horário de funcionamento e botões de contato direto (WhatsApp e Redes Sociais).
- 🌙 **Tema Moderno:** Interface visual com tons escuros e toque vintage/contemporâneo.
